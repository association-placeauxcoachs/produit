# PlaceAuxCoachs — produit

[PlaceAuxCoachs](https://placeauxcoachs.fr) est une application gratuite de création d'entraînements de handball, développée bénévolement pour les entraîneurs. Ce dépôt porte **ce qu'on décide de construire** : les idées d'évolution, les bugs signalés, les études de design et la démarche qui transforme une idée en fonctionnalité.

Le code de l'application est dans un dépôt séparé.

## Proposer une idée ou signaler un bug

Toute personne peut proposer une évolution, membre de l'association ou non. Choisissez le chemin qui vous convient :

- **Sans compte : « Donner mon avis ».** Le lien [« Donner mon avis »](https://feedback.userreport.com/2c846f13-5d17-47d7-81e4-fab83e2db988/) est en bas du site et dans le menu du compte de l'application. Le message est recopié ici en issue.
- **Avec un compte GitHub, gratuit : une issue.** Ouvrez l'onglet [**Issues**](https://github.com/association-placeauxcoachs/produit/issues/new/choose), choisissez **Fonctionnalité** pour une idée ou **Bug** pour quelque chose qui ne marche pas, et remplissez le formulaire.
- **Par e-mail**, pour une question ou un échange plus long : [support@placeauxcoachs.fr](mailto:support@placeauxcoachs.fr). Le message est recopié ici s'il propose une évolution.
- **Par le référent métier**, pour les clubs et les comités : il porte les besoins des structures du handball aux points réguliers, où les sujets sont priorisés.

Pas besoin de vocabulaire technique : racontez ce que vous vivez sur le terrain. Pour mettre une idée en forme, le [guide de travail](guide-de-travail.md) et l'[assistant produit](assistant-produit.md) peuvent aider.

Vous pouvez aussi **voter** pour une idée existante en ajoutant une réaction 👍 à l'issue, ou la **compléter** par un commentaire : un cas d'usage, une précision, une user story.

## Qui décide

Le bureau de l'association arrête les évolutions de l'application ([statuts, article 11](https://association.placeauxcoachs.fr/association/statuts/statuts.html)). À chaque réunion ordinaire, il adopte une **feuille de route** : ses axes de travail et ses critères de priorisation. Dans ce cadre, le responsable du développement, membre du bureau, instruit, priorise et livre ([règlement intérieur, article 10](https://association.placeauxcoachs.fr/association/statuts/reglement-interieur.html)). Le détail est dans la [démarche produit](demarche.md).

**Feuille de route en vigueur** : [feuille de route n° 1](https://association.placeauxcoachs.fr/association/decisions/2026-10-17-feuille-de-route-n1.html), adoptée le 17 octobre 2026, jusqu'à la réunion ordinaire du bureau de mars 2027.

## Où en sont les sujets

Le tableau [**Produit PlaceAuxCoachs**](https://github.com/orgs/association-placeauxcoachs/projects/2) montre chaque sujet et son avancement :

| Colonne | Signification |
|---|---|
| Idées en vrac | Tout ce qui arrive, rien de trié |
| À prioriser | Le problème est clair et la valeur posée ; les fiches sont triées par valeur |
| Quinzaine | Retenu pour les quinze jours qui viennent |
| En cours | En développement |
| Bêta | Livré aux bêta-testeurs |
| Livré | Ouvert à tous ; le sujet est fermé et quitte le tableau quatorze jours plus tard |
