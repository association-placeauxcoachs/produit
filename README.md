# PlaceAuxCoachs — produit

[PlaceAuxCoachs](https://placeauxcoachs.fr) est une application gratuite de création d'entraînements de handball, développée bénévolement pour les entraîneurs. Ce dépôt porte **ce qu'on décide de construire** : les idées d'évolution, les bugs signalés, les études de design et la démarche qui transforme une idée en fonctionnalité.

Le code de l'application est dans un dépôt séparé.

## Proposer une idée ou signaler un bug

1. Ouvrez l'onglet [**Issues**](https://github.com/association-placeauxcoachs/produit/issues/new/choose).
2. Choisissez **Fonctionnalité** pour une idée, **Bug** pour quelque chose qui ne marche pas.
3. Remplissez le formulaire. Pas besoin de vocabulaire technique : racontez ce que vous vivez sur le terrain.

Il faut un compte GitHub, gratuit. Sans compte, écrivez à [support@placeauxcoachs.fr](mailto:support@placeauxcoachs.fr) ou utilisez le bouton de retour en bas de chaque page de l'application : le message sera recopié ici.

Vous pouvez aussi **voter** pour une idée existante en ajoutant une réaction 👍 à l'issue.

## Où en sont les sujets

Le tableau [**Produit PlaceAuxCoachs**](https://github.com/orgs/association-placeauxcoachs/projects/1) montre chaque sujet et son avancement :

| Colonne | Signification |
|---|---|
| À instruire | L'idée est déposée, pas encore mise en forme |
| Instruit | Le besoin est formulé : problème, user stories, critères d'acceptation |
| Priorisé | Retenu au point de priorisation, prêt à être développé |
| En cours | En développement |
| En revue | Développé, en relecture avant mise en ligne |
| Livré | Disponible dans l'application |
